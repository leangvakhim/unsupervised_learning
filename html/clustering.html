Unsupervised Learning

K-Means Clustering

1. Raw Data

In unsupervised learning, we start with unlabeled data. We want the computer to find patterns on its own. Notice how these points naturally form groups, but the computer doesn't know that yet.

Objective Function (Inertia):

$$J = \sum_{j=1}^{K} \sum_{i \in C_j} || x_i - \mu_j ||^2$$
  • \( J \) = Total variance (we want this to be small)
  • \( K \) = Number of clusters
  • \( x_i \) = A data point
  • \( \mu_j \) = The centroid (center) of cluster \( j \)
  • \( || x_i - \mu_j ||^2 \) = Squared distance from point to center
